# 工作日志 AI 配置重置确认设计

## 目标

在“工作日志 → AI 配置”中，用户点击重置 AI 配置时先显示确认弹窗，只有确认后才执行重置。

## 行为

- 重置入口继续使用现有按钮和项目已有的 Ant Design `Modal.confirm` 确认样式。
- 弹窗标题：`确认重置 AI 配置`
- 弹窗内容：`将重置除 API Key 以外的全部配置，确定要继续吗？`
- 点击“取消”或关闭弹窗：不修改任何配置。
- 点击“确认”：执行现有重置逻辑，将接口地址、模型、日志模板、日志生成要求恢复为默认值，并保留 API Key。
- 确认后继续显示现有成功提示：`已恢复默认配置，API Key 未被清除`。
- 不新增依赖，不修改保存配置、生成工作日志及 API Key 存储逻辑。

## 实现范围

仅修改 `src/components/ui/WorkLogModal.tsx` 中的重置入口：将当前直接执行的 `resetAiDefaults` 改为打开确认弹窗，并将实际重置逻辑保留在确认回调中。

## 验收标准

1. 点击重置入口后会出现确认弹窗。
2. 取消确认后，所有输入值保持不变。
3. 确认后除 API Key 外的配置恢复默认值。
4. 确认后显示现有成功提示。
5. 项目构建和现有测试通过。
