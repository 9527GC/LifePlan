# 复盘弹框默认值设计

日期：2026-09-11

## 目标

新建复盘时提供合理默认值，降低填写成本；编辑已有复盘时必须保留已保存内容。

## 需求

- 新建复盘默认“是否达到预期”为“达到预期”（值 `1`）。
- 新建复盘默认“是否专注”为“专注”（值 `1`）。
- 新建复盘默认“实际工作情况”为 `[项目标题]-[行动标题]`。
- 若行动没有项目标题，则默认实际工作情况退化为行动标题，避免出现前导连字符。
- 编辑已有复盘时完整保留 `actual_notes`、`met_expectation`、`focused` 的已有值，不重新套用默认值。
- 不修改 API、数据库结构、保存逻辑和复盘列表展示。

## 实现方案

在 `DailySlotModal` 的表单初始化 `useEffect` 中区分新建和编辑：当三个复盘字段均为空时视为新建，使用行动信息构造默认值；否则直接回填现有字段。由于弹框组件使用 `destroyOnHidden`，每次打开都会重新以当前 slot 初始化表单。

## 验证

- TypeScript/Vite 构建通过。
- 新建有项目行动的复盘弹框显示 `项目标题-行动标题`、达到预期、专注。
- 新建无项目行动的复盘弹框显示行动标题、达到预期、专注。
- 编辑已有复盘时三个字段保持原值。
