# 每日计划插入时间段 Hover 触发范围设计

## 目标

将“插入时间段”按钮的 Hover 展示范围限制为每日计划表的“时间段”列。鼠标停留在“计划行动”或“复盘”列时，不展示该行下方的插入按钮。

## 方案

沿用现有 CSS 控制方式，不引入 React 状态。为时间段单元格保留明确的选择器边界，并通过同一行包装元素的后代关系，让插入按钮仅在时间段单元格处于 Hover 状态时显示。

这样可以保持现有插入按钮的点击逻辑、动画和布局不变，同时避免额外的事件状态管理。

## 行为与验证

- 鼠标停留在时间段单元格时，当前行的插入按钮显示。
- 鼠标停留在计划行动、复盘或其他空白区域时，插入按钮隐藏。
- 点击插入按钮仍打开新增时间段弹窗，并保留当前插入位置的时间预设。
- 前端构建通过，确认 TypeScript 与 CSS 相关改动无编译问题。
