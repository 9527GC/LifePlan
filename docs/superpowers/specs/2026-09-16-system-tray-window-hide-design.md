# 系统托盘常驻与窗口隐藏设计

**日期：** 2026-09-16  
**状态：** 已确认，待用户审阅

## 目标

将 LifePlan 的关闭行为调整为隐藏主窗口，而非结束应用进程。隐藏后桌面窗口和任务栏图标均消失，应用继续驻留在系统托盘中。

## 用户交互

### 关闭主窗口

- 用户点击现有窗口关闭按钮后，Tauri 拦截关闭请求。
- 主窗口改为隐藏，不销毁窗口、不退出应用。
- 隐藏后任务栏中不再显示该窗口图标；系统托盘图标继续存在。

### 托盘图标操作

- 左键单击托盘图标：显示主窗口，并恢复焦点。
- 右键单击托盘图标：打开原生上下文菜单。
- 上下文菜单提供：
  - `打开窗口`：显示主窗口，并恢复焦点。
  - `退出`：显式结束整个应用进程。

## 技术设计

### Rust 端职责

所有窗口生命周期和托盘交互均在 `src-tauri/src/lib.rs` 中处理，避免前端生命周期状态影响原生窗口关闭与退出行为。

1. 启动时创建系统托盘：
   - 复用 Tauri 应用默认图标；
   - 创建带 `打开窗口`、`退出` 项的原生菜单；
   - 设置托盘菜单事件与图标点击事件处理器。
2. 抽取窗口恢复逻辑：
   - 按标签取得 `main` 窗口；
   - 调用显示与聚焦 API；
   - 供左键单击托盘图标和菜单项共用。
3. 监听主窗口关闭事件：
   - 正常关闭请求时调用 `prevent_close`；
   - 随后隐藏窗口；
   - 不触发应用进程退出。
4. 处理真正退出：
   - 用户选择 `退出` 菜单项时调用应用退出 API；
   - 不拦截该显式退出流程，确保进程和托盘一并关闭。

### 依赖与配置

- 检查 `src-tauri/Cargo.toml` 的 Tauri 特性，确保启用 `tray-icon`。
- 不增加独立第三方托盘依赖。
- 不修改前端 React 代码、窗口样式或现有自定义标题栏布局。

## 边界行为

- 当窗口已显示时，点击托盘图标或“打开窗口”仅执行显示和聚焦，保持幂等。
- 只有选择托盘菜单中的“退出”才会结束应用；窗口关闭不会退出。
- 在开发与打包环境中均使用同一套 Rust 生命周期逻辑。

## 验收标准

1. 点击主窗口关闭后，窗口消失，任务栏中没有该窗口图标，系统托盘图标仍存在。
2. 左键点击系统托盘图标，主窗口显示并获得焦点。
3. 右键系统托盘图标可见“打开窗口”和“退出”两个菜单。
4. 点击“打开窗口”可恢复并聚焦主窗口。
5. 点击“退出”后，应用进程及其系统托盘图标全部退出。
