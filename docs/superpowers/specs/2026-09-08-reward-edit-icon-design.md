# 奖励卡片编辑按钮图标化设计

- 日期：2026-09-08
- 范围：奖励池奖励卡片的编辑操作

## 目标

奖励卡片的编辑按钮仅显示现有铅笔图标，移除“编辑”文字，不增加 tooltip 或 `title` 文案。

## 方案

仅修改 `src/pages/Rewards.tsx` 中奖励卡片编辑按钮的 JSX：保留 `Pencil` 图标、按钮点击处理器 `showForm(reward)` 以及现有按钮类型和尺寸，删除按钮文本“编辑”。不调整删除、兑换按钮，也不修改其他页面或通用样式。

## 验收标准

1. 奖励池每张奖励卡片的编辑操作只显示铅笔图标。
2. 点击编辑图标仍能打开对应奖励的编辑表单。
3. 编辑按钮不显示 tooltip 或 `title` 文案。
4. 删除和兑换操作保持现状。
5. 项目 TypeScript 检查和构建通过。
