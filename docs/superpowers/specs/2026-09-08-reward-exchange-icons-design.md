# 兑换记录奖励图标展示设计

## 目标

在“奖励池”的“兑换记录”中，为每条记录的奖励名称前展示对应奖励图标，并通过适度留白提升可读性。

## 范围

- 仅修改兑换记录列表的前端展示。
- 不修改数据库结构、后端接口和兑换数据模型。
- 不调整奖励池卡片及奖励编辑器中的现有图标展示。

## 展示方案

兑换记录每行采用“图标 + 奖励名称 + 兑换详情”的横向布局：

- 根据记录的 `reward_id` 从当前奖励池 `data.rewards` 中匹配奖励图标。
- 匹配不到图标时使用默认图标 `🎁`，兼容已归档或历史数据。
- 图标使用约 28px × 28px 的圆角浅色背景容器。
- 图标与奖励名称保持约 10px 间距。
- 每条记录增加上下留白，记录之间不采用过密排列。
- 兑换积分和时间继续使用现有的次要信息样式。

## 技术实现

- 修改 `src/pages/Rewards.tsx`：在兑换记录渲染处查找对应奖励，并增加图标节点及语义化结构。
- 修改 `src/App.css`：增加兑换记录内容容器、图标和名称的布局样式；保留现有 `.exchange-row` 的整体结构并适度放宽行内间距。
- 使用现有奖励 `icon` 字段，不新增依赖。

## 验收标准

1. 每条兑换记录的奖励名称前都有图标。
2. 正常记录显示与奖励池一致的图标。
3. 找不到对应奖励或图标为空时显示 `🎁`。
4. 图标、名称、兑换详情之间有清晰间距，记录行不显得拥挤。
5. 窄屏下内容不会溢出，兑换时间仍可正常展示。
6. 项目现有 TypeScript 检查和构建通过。
