# 系统托盘恢复最小化窗口设计

**日期：** 2026-09-16  
**状态：** 已确认，待用户审阅

## 目标

使系统托盘左键点击和右键菜单中的“打开窗口”在主窗口最小化时，也能将窗口恢复到可见桌面并获得焦点。

## 问题原因

当前统一窗口恢复函数只调用 `show()` 和 `set_focus()`。窗口处于最小化状态时，必须先调用 Tauri 的 `unminimize()`，否则窗口仍保持最小化，用户无法看到窗口。

## 技术设计

仅修改 `src-tauri/src/lib.rs` 中的 `show_main_window`：

1. 取得 `main` 主窗口；
2. 调用 `is_minimized()` 查询状态；
3. 若状态为最小化，调用 `unminimize()`；
4. 继续调用既有 `show()` 和 `set_focus()`。

系统托盘左键事件与“打开窗口”菜单已经共用 `show_main_window`，不需要修改托盘菜单、点击事件或关闭拦截代码。

## 边界行为

- 窗口隐藏后：`unminimize()` 不会造成额外影响，随后 `show()` 会正常恢复窗口。
- 窗口已显示且未最小化：跳过 `unminimize()`，只执行显示与聚焦，维持幂等。
- 关闭窗口驻留托盘、托盘左键、右键菜单以及“退出”菜单的既有行为保持不变。

## 验收标准

1. 窗口最小化后，左键点击系统托盘图标，窗口恢复并获得焦点。
2. 窗口最小化后，右键系统托盘图标并点击“打开窗口”，窗口恢复并获得焦点。
3. 窗口关闭并隐藏后，以上两种恢复方式仍然正常。
4. 点击“退出”后应用仍能完全退出。
