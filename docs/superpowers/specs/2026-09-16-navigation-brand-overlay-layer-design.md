# 导航品牌区与遮罩层级设计

- 日期：2026-09-16
- 状态：待用户审阅

## 目标

调整左上角 Logo 与更新图标的显示层级：二者处于相同的品牌区层级，高于左侧导航菜单和顶部导航；当任意带遮罩的界面打开时，品牌区必须位于其遮罩之下。

适用的遮罩界面包括 Ant Design Modal、Drawer、确认类弹层，以及应用的新手引导。

## 方案

采用显式的应用层级划分：

1. 导航基础内容保持默认或较低层级。
2. Logo 与更新图标归属同一个品牌区容器，并由该容器统一设置 `z-index`，保证两者层级一致。
3. 品牌区层级高于左侧导航和顶部导航，确保常规页面中始终可见。
4. 不修改 Ant Design Modal、Drawer 等组件的默认高层级；其遮罩与内容自然覆盖品牌区。
5. 新手引导的遮罩和内容层级显式高于品牌区，避免其受局部定位或堆叠上下文影响而被品牌区穿透。

## 改动范围

- `src/components/layout/Layout.tsx`：仅在现有结构无法表达统一品牌区层级时，补充语义化容器或类名。
- `src/App.css`：定义导航基础层与品牌区层级，确保 Logo 和更新图标共享同一层级。
- `src/components/ui/OnboardingCarousel.tsx`：核验并必要时提升新手引导遮罩/内容层级。

## 验收标准

1. 未打开弹层时，Logo 与更新图标显示在左侧导航菜单和顶部导航上方。
2. Logo 与更新图标不存在彼此遮挡或不同层级的情况。
3. 打开任意 Modal、Drawer、确认类弹层时，遮罩能覆盖 Logo 与更新图标，且两者不可点击。
4. 打开新手引导时，引导遮罩同样覆盖 Logo 与更新图标。
5. 不改变导航、更新检查、更新安装或弹层的原有交互行为。
