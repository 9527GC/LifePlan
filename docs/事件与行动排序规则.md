# 事件与行动排序规则

> 更新时间：2026-10-27；当前工作区规则，包含未发布更新。

同优先级（P1、P2、P3、P4）内青蛙优先，不跨越优先级。日期、状态和手动排序继续按各入口原有规则处理。

| 入口 | 排序规则 | 实现位置 |
| --- | --- | --- |
| 事件篮进行中事件 | 可直接完成的事件置顶 → P 级 → 青蛙 → 原顺序 | `Inbox.tsx`、`prioritySort.ts` |
| 事件篮待处理、已委托、已放弃、已完成 | 沿用接口的更新时间倒序 | `events.rs` |
| 事件篮推迟事件 | 重新处理日期 → 创建时间 → 编号 | `Inbox.tsx` |
| 今日事安排行动，平铺视图 | 有日期优先 → 开始日期升序 → P 级 → 青蛙 → 原顺序 | `dailyActionSort.ts` |
| 今日事安排行动，事件视图的事件分组 | P 级 → 青蛙 → 原顺序 | `DailyList.tsx`、`prioritySort.ts` |
| 事件篮和今日事事件视图，事件内行动 | 按开始日期排列，同日保留手动顺序；未设置日期的行动保留原位置 | `eventActionSort.ts` |
| 日期联动中的后续行动 | 使用打开弹框时的当前视图排序快照确定范围 | `DailyList.tsx`、`Inbox.tsx` |
| 重复行动模板列表 | 手动顺序 → 编号 | `recurring_actions.rs` |
| 重复行动自动安排 | 模板手动顺序，按已配置时间安排 | `recurring_actions.rs` |
| 今日事日程和每日复盘 | 日程时间顺序 | `daily_schedule.rs` |
| 番茄钟关联今日行动下拉框 | 接口默认顺序：事件行动优先 → 有开始日期优先 → 开始日期 → 保存顺序 → 编号 | `Pomodoro.tsx`、`actions.rs` |
| 旧每日清单接口 | 清单手动顺序 → 编号 | `daily_list.rs` |

事件内部的未完成行动统一继承事件青蛙标签，因此不额外按青蛙排序；已完成行动保留历史标签，也不因标签打乱日期或手动顺序。

青蛙排序仅用于已有优先级排序的入口；P 级数值及其重要程度、紧急程度计算方式不变。

## 青蛙排序示例

- 同为 P1 的事件，青蛙事件先于普通事件；P2 青蛙事件不会越过 P1 普通事件。
- 平铺行动中，10 月 27 日的普通行动仍早于 10 月 28 日的青蛙行动；同一天、同 P 级时青蛙行动优先。
- 同一事件的未完成行动青蛙标签一致，事件内不再额外排序；按事件查看时只在事件标题显示青蛙标签。
- 青蛙、P 级和日期都相同时保留原顺序，不额外按名称或编号重排。
