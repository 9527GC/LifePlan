# 行动日期超期提醒测试用例

## 验收规则

- 选择开始日期后立即判断；仅当开始日期晚于所属事件截止日期时，在当前弹框内持续展示黄色提示及截止日期。
- 提示不依赖点击保存，不使用超期 toast，不要求再次确认，不阻止选择和保存。
- 改回截止当日或更早、清空开始日期后，提示立即消失。未设置事件截止日期时不提示。
- 当前行动无独立结束日期字段；历史行动截止日期不参与判断。

## 公共边界

以下用例在“添加行动、编辑行动、拆解行动、单条调整开始日期”分别执行，事件截止日期设为 2026-10-26。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| D01 | 选择 2026-10-25 | 无超期提示，可保存 |
| D02 | 选择 2026-10-26 | 无超期提示，可保存 |
| D03 | 选择 2026-10-27，不点击保存 | 日期被接受，弹框内立即出现超期提示，保存按钮可用 |
| D04 | 保持 D03 日期后保存并重新打开 | 保存成功，日期保留，编辑入口展示对应超期提示 |
| D05 | 超期后改为 2026-10-26 | 提示立即消失，可保存 |
| D06 | 超期后清空开始日期 | 提示立即消失，可保存空日期 |
| D07 | 未设置事件截止日期，选择未来日期 | 无超期提示，可保存 |
| D08 | 截止 2026-10-31，选择 2026-11-01；截止 2026-12-31，选择 2027-01-01 | 跨月、跨年均立即提示且可保存 |
| D09 | 保存超期日期 | 不弹出超期 toast、不增加确认弹框，可保留正常保存成功提示 |

## 入口及状态回归

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| S01 | 编辑已有超期行动 | 打开后可见提示，不必再次选日期 |
| S02 | 关闭超期行动弹框，再添加新行动或编辑其他行动 | 日期和提醒不串到其他行动 |
| S03 | 拆解多条行动，其中两条超期 | 对应行动行下展示提示，其余行无提示；整批可保存 |
| S04 | 拆解时删除超期行、清空日期或改回正常日期 | 对应提示随行状态立即消失 |
| S05 | 拆解时新增行动并继承上一条超期日期 | 新行立即展示提示，可继续修改和保存 |
| S06 | 拆解时返回上一步，将截止日期延后、提前或清空，再进入拆解 | 保留行动日期，按最新截止日期更新各行提示 |
| S07 | 联动后延导致部分后续行动超期 | 预览中超期日期标红；黄色提示仅展示“开始日期已超过事件截止日期”，不重复展示行动明细；确认调整可用，全部修改成功 |
| S08 | 联动产生超期后取消勾选联动 | 预览和提示仅按当前行动重新计算 |
| S09 | 联动清空开始日期 | 无超期提醒；原有日期清空，无日期行动不产生无效修改 |
| S10 | 联动中已完成、其他事件或未设开始日期的行动 | 保持既有联动范围规则，不因超期提醒扩大修改范围 |
| S11 | 同一天未修改日期 | 无有效修改时确认按钮仍禁用；与超期状态无关 |
| S12 | 延后或取消事件截止日期，行动有历史截止日期 | 仅以当前所属事件截止日期判断 |
| S13 | 超期同时标题为空 | 仍执行标题必填校验；超期本身不阻止保存 |
| S14 | 联动保存前行动被其他操作修改 | 仍拒绝覆盖新数据，并显示已有并发修改错误 |
| S15 | 弹框出现多条超期提示 | 正文可滚动，标题及底部操作区可见，无固定高度留白 |
