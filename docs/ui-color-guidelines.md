# 界面颜色规范

> 更新时间：2026-10-12。以当前工作区为准，覆盖今日专注、积分流水与每日清单优先级标签；不表示全站硬编码颜色已全部迁移。

## 基本原则

- 业务状态优先复用 Ant Design theme.useToken() 与 Tag 预设颜色，避免为同一语义随意增加色值。
- 颜色配合文字、图标或图例，不仅依靠颜色传达状态。
- 中断使用橙色；失败或扣分使用错误色，正常休息不是警告。

## 今日专注

| 语义 | 时间轴令牌 | 统计卡片文字 / 背景 / 边框 | 标签 |
| --- | --- | --- | --- |
| 专注时长、工作阶段 | blue-4 | blue-7 / blue-1 / blue-3 | 进行中：blue |
| 进行中的结束标记 | blue-6 | — | blue |
| 休息、已完成 | 休息：green-6 | green-7 / green-1 / green-3 | 已完成：green |
| 中断 | orange-6 | orange-7 / orange-1 / orange-3 | 已中断：orange |
| 历史已放弃 | — | — | default，标注历史记录 |

TodayFocus 通过 --focus-work-color、--focus-current-color、--focus-rest-color、--focus-interrupted-color 映射时间轴颜色，番茄钟与每日复盘共用。

## 积分流水

| 来源 | 标签颜色 |
| --- | --- |
| 专注奖励 | blue |
| 事件完成 | green |
| 奖励兑换 | gold |
| 奖励撤回 | error |
| 历史余额调整 | 默认中性色 |

金额独立表示收支：正数使用 colorPrimary 并带 +，负数使用 colorError，零使用 colorTextSecondary。分隔线使用 colorBorderSecondary，时间使用次级文字样式。标签表示来源，金额表示增减，不应混用。

## 每日清单优先级

每日清单计划行动与行动预览的“优先级 Pn”标签使用紫色，区别于行动蓝色背景；不改变其他页面优先级和行动背景。见 [原始设计](superpowers/specs/2026-09-04-daily-priority-tag-color-design.md)。

## 布局与弹框

- 普通弹框复用 src/App.css 通用高度逻辑，短内容自适应，长内容保留窗口上下各 16px 安全间距，只让正文滚动。
- 标题和操作区保持可见；积分流水保留列表独立滚动和分页，不设置固定视口高度。
- 复盘记录渐隐只提示更多内容，不代表数据缺失或未完成。

## 验证清单

核对统计、图例、标签语义及正负金额符号；检查窄 / 矮窗口和长列表的滚动与操作区可见性。运行前端构建与后端测试；编译通过不替代视觉验收。
