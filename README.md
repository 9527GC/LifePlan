# LifePlan

LifePlan 是一款**本地优先**的桌面时间管理工具，帮助你通过“收集事件 → 拆解行动 → 安排今日 → 专注执行 → 每日复盘”建立个人执行闭环。

## 当前功能

- **今日事与日程**：按日期安排事件行动、临时行动和重复行动；支持时间段、计划模板、执行记录与时间段复盘。重复行动支持每天、每周指定星期和每月指定日期，可在启动当天或复盘进入次日计划时自动安排到空白时间段。
- **事件篮**：收集事项，并按自己做、委托、推迟、放弃等方式处理；进行中的事件可直接管理行动。推迟事件设置重新处理日期后，将在该日期前一个自然日的本地时间 17:00 恢复至推迟前的状态；未设置日期时仅手动恢复。应用关闭或休眠时错过恢复时间，会在下次打开或激活窗口时补恢复。
- **今日专注**：番茄钟与每日复盘共用专注统计、时间轴和记录，展示今日专注分钟数、完成次数、中断次数及原因。
- **番茄钟**：可关联今日行动，记录专注、完成和中断；进行中的专注可切换为独立的置顶悬浮窗口，完成后可直接进入每日复盘或开启下一次专注。
- **每日复盘**：基于当天日程和行动完成情况查看执行摘要、偏差与建议，并自动保存 Markdown 复盘思考；显示保存中、保存时间或失败状态，进入明日计划前先初始化次日重复行动。
- **奖励池与积分流水**：通过完成事件和专注积累积分，兑换自定义奖励并记录打卡；从奖励池或番茄钟积分入口查看流水，支持类型筛选与分页。
- **问题反馈**：通过窗口顶部标题栏的“问题反馈”按钮提交 Bug、建议或疑问，可选附带截图、联系方式和脱敏诊断信息。

> 本文包含当前工作区尚未发布的功能，发布状态见 [更新日志](CHANGELOG.md)。重复行动每个空间、每个日期只自动初始化一次，不覆盖已有安排，修改模板不会回填当天；旧模板需编辑保存规则后启用。详见 [产品说明](docs/人生规划软件%20V1.0.md)中的“重复行动与习惯”。

## 事件与行动设置

- 事件可标记为青蛙，未完成行动统一继承；已完成行动保留历史标签。重复行动模板及临时行动保留独立青蛙设置。
- 同 P 级青蛙事件优先；今日事平铺选择行动先按开始日期，再按 P 级和青蛙标记排序。事件内部仍保留日期与同日手动顺序，详见 [排序规则](docs/事件与行动排序规则.md)。
- 事件篮编辑行动和今日事日期调整均可联动提前、后延或清空同事件后续未完成行动日期，提供变更预览并整批保存。
- 事件卡片按需显示截止日期，已完成事件显示完成日期；进行中事件当天或逾期标红，剩余 1–4 天标橘，5 天及以上为灰色。
- “去处理”回显已设置的事件信息；两分钟小事可直接完成，无需拆解行动。

## 隐私与数据

- 业务数据保存在本地 SQLite 数据库中，日常使用不依赖云同步。
- 本地操作日志不记录事件标题、行动标题、目标、备注、复盘正文、文件路径或数据库内容。
- 提交反馈时，只有勾选“附带应用诊断信息和操作日志”才会发送版本、平台、当前页面及脱敏操作日志；不勾选时不会发送这些信息。截图和联系方式均由用户自主填写。

详细的产品边界见《[人生规划软件 V1.0](docs/人生规划软件%20V1.0.md)》，每日复盘规则见《[每日复盘功能说明](docs/daily-review-development.md)》。

行动开始日期超过所属事件截止日期时，仅在弹框内提示，不阻止选择或保存。日期选择器按日历实际尺寸适配可用空间，空间不足时使用独立日期弹框，输入区和操作按钮保持可见。

## 开发环境

### 前置要求

- Node.js 20 或更高版本
- Rust stable 工具链
- Tauri 2 的系统依赖（按目标平台安装）

### 安装与运行

```bash
npm install
npm run dev
```

`npm run dev` 仅用于前端界面调试；本地数据库及 Tauri 命令等完整业务功能需在桌面端运行。

启动桌面端开发环境：

```bash
npm run tauri dev
```

构建前端：

```bash
npm run build
```
